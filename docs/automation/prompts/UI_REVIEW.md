# Review ShopOps UI evidence

```text
Review the preview for issue <ISSUE_URL> using the acceptance criteria and
ShopOps' existing visual system. Check desktop and mobile and inspect loading,
empty, populated, error and restricted-role states when applicable.

Evaluate hierarchy, primary action clarity, information density, spacing,
Polaris/Admin consistency, responsive tables/charts, contrast, keyboard use,
labels, focus states and error recovery. Protect the existing role and location
scope behavior.

Return only BLOCKER, MUST FIX, SHOULD FIX and POLISH findings. Attach a concrete
screen/state to each finding. Do not suggest a redesign unless the acceptance
criteria require one. Distinguish objective accessibility/functional failures
from subjective visual preferences.
```
